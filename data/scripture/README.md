# Local Scripture corpus

This directory contains the complete 66-book **World English Bible, Protestant Edition (WEBP)** as local JSON for Scripture lookup, summarization context, and reference validation.

- Translation: World English Bible (WEBP)
- Canon: 66-book Protestant canon
- Rights: public domain
- Official upstream: https://ebible.org/details.php?id=engwebp
- Official USFM distribution: https://ebible.org/Scriptures/engwebp_usfm.zip
- JSON conversion source snapshot: Arcdub/sower at commit 29daf46e31118569fd65b8d319d334746bd23432
- Conversion source path: `app/src/en/assets/bible/`

The local files preserve verse text; the application adds normalized canonical IDs such as `ROM.2.14` at lookup time.

Do not add copyrighted ESV text here. Reader-facing ESV access is provided through generated YouVersion links.
