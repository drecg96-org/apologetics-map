# Question

The argument from consciousness should not be:

> Consciousness is mysterious; therefore God.

It asks instead whether a world containing conscious subjects is more naturally expected if mentality is fundamental than if fundamental reality is wholly nonmental.

Even if the answer favors mind-first metaphysics, theism must still outperform panpsychism, idealism, and other alternatives.
