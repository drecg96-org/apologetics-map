# Question

The comparison should be many-sided.

The live options include:

- real bodily resurrection;
- vision or bereavement experience;
- legend and tradition development;
- cognitive-dissonance or expectation-revision mechanisms;
- mistaken identity for some reports;
- body relocation or removal if an empty tomb is granted;
- and mixed models using more than one natural mechanism.

The right question is not "Can I invent a possible alternative?" It is:

> Which model has the best combination of evidential fit, explanatory scope, background plausibility, simplicity, and non-ad-hoc support?

The formal argument mapper represents both a Christian abductive case and a skeptical vision-plus-development case.
