# Claim

A temporal-beginning argument is distinct from a contingency argument.

If all physical reality began to exist, then—given an appropriate causal principle—the explanation cannot simply be an earlier physical event in the same history.

## Limit

Current cosmology should not be used as a shortcut to the premise **physical reality had an absolute beginning**. The philosophical and cosmological questions must remain separate.
