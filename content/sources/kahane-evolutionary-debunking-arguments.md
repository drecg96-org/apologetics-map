# Agent summary

Kahane distinguishes different evolutionary debunking arguments instead of treating them as one inference. He argues that their skeptical force depends on specific epistemic premises and that targeted debunking arguments can overextend.

## How to use this source

Use to sharpen both the evolutionary objection and replies to it.
