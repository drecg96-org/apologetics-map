# Source profile

A neutral philosophical framework for asking how a purported revelation can be recognized as divine rather than merely asserted to be so.

The entry is useful for distinguishing:

- what revelation would be if genuine;
- testimony internal to a revelation;
- publicly accessible signs proposed to authenticate a revelation;
- and the epistemic circularity problem that arises when a source's authority is established only by that same source.
