# Source profile

A reference point for the claim that omnipotence is normally analyzed as **maximal power**, not as the ability to make contradictions true.

That distinction matters in free-will discussions. If "God causes this person to choose A while the choice is wholly undetermined by God" describes an incoherent state of affairs under a libertarian account of freedom, inability to actualize that description would not straightforwardly count as a loss of omnipotence.

The source does not establish libertarian freedom or solve the problem of evil. It only helps keep the divine-attributes question separate from the further debate over which account of freedom is correct.
