# Agent summary

Blackburn argues that ethical thought can arise from motivational and emotional states while still supporting disciplined reasoning and many surface features associated with realism. Quasi-realism therefore challenges inferences from ordinary moral language directly to realist ontology.

## How to use this source

Use when asking whether moral truth-talk, disagreement, and error require robust realism.
