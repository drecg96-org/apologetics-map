# Agent summary

This chapter lays out several ways moral phenomena can be used in arguments toward theism. Its value for the map is methodological: the moral case can be cumulative, with distinct arguments from value, obligation, knowledge, and human dignity.

## How to use this source

Use to prevent the moral argument from being represented as only one deductive syllogism.
