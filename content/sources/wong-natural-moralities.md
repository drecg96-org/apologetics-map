# Agent summary

Wong rejects unrestricted relativism and a single uniquely correct complete morality. Shared human needs constrain viable systems while still allowing genuine pluralism in moral priorities.

## How to use this source

Use as a strong relativist position that preserves criticism and common constraints without robust global realism.
