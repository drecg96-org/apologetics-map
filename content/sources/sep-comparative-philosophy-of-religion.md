# Agent summary

This entry provides methodological context for comparing religious traditions rather than simply measuring one tradition by another tradition's internal categories. It is useful for questions about religious diversity, cross-tradition reasoning, and the standards by which rival revelation claims should be assessed.

## How to use this source

Use it to discipline the comparison method. It should not be treated as evidence for Christianity, Judaism, or Islam in particular.
