# Source profile

Use this source to describe New Testament transmission without either apologetic extreme.

The manuscript tradition contains real variation and requires critical reconstruction. At the same time, textual criticism is precisely the discipline for comparing witnesses and establishing an earliest attainable text.

Textual recoverability and theological inspiration are separate questions.
