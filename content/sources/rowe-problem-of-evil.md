# Source profile

Rowe's argument is important because it does not require the strong claim that God and evil are logically incompatible.

Instead it asks whether there are instances of intense suffering for which we have no good reason to think an omnipotent, omniscient, perfectly good God would need to permit them. If so, those cases may count as evidence against that form of theism.

Rowe also explicitly allows that some theists may still be rational, which makes this a useful source for representing skeptical pressure without caricaturing either side.
