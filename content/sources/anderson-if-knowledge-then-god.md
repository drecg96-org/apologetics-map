# Agent summary

Anderson compares a set of epistemological arguments inspired by Alvin Plantinga and Cornelius Van Til. The shared theme is that God's existence is in some important sense a precondition of human knowledge, but the arguments differ in what epistemic phenomenon they begin with and how strong a conclusion they seek.

## How to use this source

Use to decompose broad TAG rhetoric into smaller epistemological arguments that can be evaluated separately. It is also useful evidence that there is no single uncontested "knowledge therefore God" formulation.
