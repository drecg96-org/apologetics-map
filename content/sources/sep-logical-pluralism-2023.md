# Source profile

Logical pluralists argue that there can be more than one correct logic or correct logical consequence relation. The literature includes disputes over classical, intuitionistic, relevant, and paraconsistent consequence as well as the normativity of logic.

## How to use this source

The point is not that logic is subjective. It is that a transcendental argument must specify which logical facts require grounding and why their structure supports the proposed metaphysical conclusion.

## Limitation

Logical pluralism does not imply that there are no objective logical truths, and it does not itself count against theism.
