# Agent summary

Streumer presses anti-realism across the normative domain rather than selectively targeting morality. This is especially relevant to companions-in-guilt arguments because it shows that an anti-realist can accept the wider skeptical cost instead of conceding moral realism.

## How to use this source

Use as the strongest terminal reply to 'but epistemic oughts are objective': a consistent opponent may extend error theory to normativity more generally.
