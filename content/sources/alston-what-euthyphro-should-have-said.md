# Agent summary

Alston develops a theistic response in which God's nature can function as the ultimate standard without making morality a product of arbitrary commands. The proposal still leaves room for questions about explanatory stopping points.

## How to use this source

Use alongside Adams and contemporary divine-nature responses to the Euthyphro dilemma.
