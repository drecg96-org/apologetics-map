# Agent summary

This entry defines transcendental arguments in terms of claims that one condition is necessary for the possibility of another phenomenon the skeptic is expected to grant. It reviews their Kantian background, ambitious anti-skeptical uses, Barry Stroud's influential objection, and later proposals for more modest roles.

## How to use this source

Use it to define the argument form neutrally and to prevent Christian TAG from being described as though "transcendental argument" were itself a uniquely theological category. It is also the best overview source for the gap between proving a condition of thought and proving that the corresponding external reality exists.
