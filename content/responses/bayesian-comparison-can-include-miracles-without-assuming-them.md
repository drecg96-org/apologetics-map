# Response

One need not begin by assigning resurrection either probability 0 or probability 1.

A Bayesian-style comparison can ask:

- what the background probability of God is;
- how likely resurrection would be if God exists and has relevant purposes;
- how likely the evidence is if resurrection occurred;
- and how likely the same evidence is under rival naturalistic models.

## Limit

This framework does not make the result neutral or automatic.

The inputs—especially background theism and divine purposes—are themselves deeply disputed. The value of the approach is that it exposes those assumptions rather than hiding them.
