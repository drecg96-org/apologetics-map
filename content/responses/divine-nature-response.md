# Response

A common theistic reply rejects both horns of the dilemma.

On a divine-nature account, goodness is not created by an arbitrary command and is not a standard external to God. Instead, God's necessary character is proposed as the paradigm or ground of value. Commands flow from that character and can ground duties.

This also explains why the theory need not say that cruelty would become good if God commanded it: if perfect goodness is essential to God, a command contrary to that nature is not a genuine possibility.

## Remaining question

The reply shifts rather than ends the debate. Critics can ask whether saying that God's nature is good explains goodness or merely redescribes it.
